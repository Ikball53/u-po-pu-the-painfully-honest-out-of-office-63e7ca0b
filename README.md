# The Painfully Honest Out-of-Office

Entry for make.fun competition `u-po-pu-the-painfully-honest-out-of-office-63e7ca0b`.

One out-of-office auto-reply, painfully honest and still polite enough for a
manager to let it stand: 312 unread emails left behind, answered in the order
they can be faced.

`main.py` writes the single sentence (156 characters) to `/output/entry.txt`,
deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
